PROJECT 01

AVISS

스마트 항만 접안 모니터링 시스템 · Web / Mobile · 씨드로닉스 · 1인 QA

01 Project Overview

선박 접안 및 선석 운영 상태를 모니터링하는 서비스입니다. 모니터링·ECDIS·스케줄 등 복수 화면에서 상태와 일정 정보가 일관되게 제공되는지가 핵심 검증 대상입니다.

02 My Role

요구사항 분석, 테스트 계획·케이스 설계, 기능·회귀 검증, 이슈 등록·수정 확인, 배포 후 모니터링을 단독 담당했습니다.

03 QA Strategy

  • 접안 단계별 상태 전이와 모니터링·ECDIS·스케줄 간 데이터 정합성 검증
  • 기능 명세, 경계값·예외 조건, 권한, 운영 상황을 고려한 리스크 기반 테스트
  • 고객사별 버전·웹·모바일 검증과 배포 후 운영 체크리스트 관리

04 Key Challenges

접안·이안처럼 시간에 따라 바뀌는 상태와 외부 데이터의 차이 때문에 단순 화면 확인만으로는 오류를 판단하기 어려웠습니다. 서로 다른 정보 출처를 비교하고, 상태별 확인 시점을 구분해 테스트했습니다.
